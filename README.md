# Rock Rangers: The Great Rock Crew Quest

20-minute Grade 8 rock types identification game (37 students, phone or paper).

- `Rock_Rangers_Clue_Cards.pdf` - printable kit (A4): ranger kit, 6 clue cards, team answer slip, teacher answer key (page 4, do not print for students)
- `generate_cards.py` - script that builds the PDF (requires `reportlab`)

Rounds: Clue Hunt, Rock Pitch (speaking), Reveal and Echo, Exit ticket. Scoring: 30 points (Accuracy 18, Speaking 8, Teamwork 4).
